  3. 입국 목적은 "관광"으로만 소명, 취업·취재 등 다른 활동은 별도 비자 필요
  4. 숙박 등록(주숙등기)은 호텔 체크인 시 자동 처리됨
📖 참고: 2026 중국 여행 비자 면제! 30일 무비자 입국 준비물 (트립스토어)

② 온라인 입국카드 사전 작성

2025년 11월 20일부터 중국 입국카드가 온라인/모바일 사전 작성으로 전환되었습니다. 종이 신고서 없이 QR코드로 대체됩니다.

  1. 중국 정부서비스 플랫폼(국가이민관리국 온라인 신고 사이트)에 접속
  2. 영어 또는 중국어로 제공되므로, 크롬 브라우저의 자동번역 기능으로 한국어 확인 가능
  3. 여권정보·항공편·숙소 정보(호텔명, 주소) 입력 — 가족 동반 시 대표자가 인원별로 각각 입력 가능
  4. 제출 후 생성되는 QR코드를 화면 캡처 또는 저장 (입국 시 제시)
  5. ⚠️ 공항마다 양식이 다를 수 있어, 반드시 홍차오공항용 신고서인지 확인

③ 알리페이(Alipay) 설치 & 카드 등록

중국 전역 QR결제의 사실상 표준. 해외 발급 카드를 그대로 등록해 충전 없이 결제 가능합니다.

  1. App Store / Google Play에서 "Alipay" 검색 후 설치
  2. 휴대폰 번호(한국 번호 가능)로 회원가입
  3. 내정보(Me) → Bank Cards → 카드번호·유효기간·CVC 입력 (VISA/Mastercard/JCB/AMEX 등 대부분 가능)
  4. 본인 인증(여권 정보 등) 완료 후 등록 — "Tour Pass"에 카드를 연동하면 충전 없이 바로 결제 가능
📖 참고: 알리페이 카드등록 방법·오류·안됨·트래블월렛·로그·여권 (브런치)

④ 위챗페이(WeChat Pay) 설치 & 카드 등록

알리페이와 함께 양대 결제수단. 일부 로컬 식당·노점은 위챗페이만 받는 경우도 있어 함께 준비 권장.

  1. App Store / Google Play에서 "WeChat" 검색 후 설치
  2. 등록 → 모바일로 등록 → 이름/지역(South Korea)/한국 휴대폰 번호 입력 후 비밀번호 설정
  3. 나(Me) → 결제 및 서비스 → 지갑 → 은행카드 추가(Add a Bank Card)
  4. 해외 발급 카드(Visa·Mastercard·JCB·Amex 등) 등록 가능. 실명인증 단계에서 안면인식이나 서류 제출을 요구할 수 있음
📖 참고: [2025 최신] 위챗페이 가입·설정·인증 완전정복

⑤ 고덕지도(高德地图 / Amap) 설치

중국에서 구글맵이 정상 작동하지 않으므로 필수. 길찾기·택시 호출까지 한 앱에서 가능.

  1. App Store / Google Play에서 "Amap" 또는 "고덕지도" 검색 후 설치
  2. 설치 후 위치 권한 허용하면 회원가입 없이도 기본 검색·즐겨찾기 등록 가능
  3. 설정에서 언어를 한국어 또는 영어로 변경 (기본은 중국어)
  4. 주요 목적지(호텔, 테니스장 등)를 미리 즐겨찾기에 저장해두면 현지에서 편리
📖 참고: 고덕지도 가입 방법, 다운로드부터 설치 및 오류까지 정리

⑥ (선택) 디디추싱(滴滴出行/DiDi) 사전 가입

중국판 우버. 미리 가입해두면 현지에서 바로 택시 호출 가능.

  1. App Store / Google Play에서 "DiDi" 검색 후 설치 (위챗/알리페이 내 미니앱으로도 이용 가능)
  2. 국제전화번호(+82, 한국 번호)로 인증 가입
  3. 설정(设置) → 언어를 영어로 변경
  4. 결제수단으로 알리페이/위챗페이 또는 해외카드 연결
📖 참고: 중국 택시 어플 디디 사용법 총정리 (라이프밸런스)

기타 준비물

  1. 데이터 로밍 또는 중국용 유심/이심(eSIM) 준비 — 도착 직후 인터넷 연결 필요
  2. 보조배터리, 멀티어댑터(중국은 한국과 콘센트 모양 다를 수 있음)
  3. 여권 사본(사진) 별도 보관

💳 알리페이(Alipay) 사용법

  2. 연동해둔 해외카드로 자동 결제, 별도 충전 불필요 (Tour Pass 연동 시)
  3. 택시·공유자전거 등도 알리페이 내 미니 프로그램으로 이용 가능
  4. 결제 전 화면 상단 결제금액(위안화)을 반드시 확인

🚕 디디추싱(DiDi) 사용법

  1. 앱 실행 → 출발지/도착지 입력 (고덕지도 주소를 복사해서 붙여넣으면 편리)
  2. 차량 등급 선택(이코노미 등) → 예상 요금 확인 후 호출
  3. 결제는 알리페이/위챗페이 또는 등록한 해외카드로 자동 결제
  4. 기사님이 위치 확인차 전화할 수 있어, 한국 번호(+82) 국제전화 수신이 가능하도록 로밍/데이터 설정 필요
  5. 상하이 기본요금은 약 16위안부터 시작
📖 참고: 디디추싱 사용법: 중국 택시 앱 호출부터 기사 전화 대응까지 (Speakable)

🗺️ 고덕지도(Amap) 사용법

  1. 목적지 검색(한글 지원) → 도보/대중교통/택시 경로와 소요시간 확인
  2. 지하철 경로 안내 시 정확한 호선·환승·출구 번호까지 안내됨
  3. 앱 내에서 바로 택시(디디 등)를 호출하는 기능도 있어 앱 두 개를 오갈 필요가 적음
  4. 즐겨찾기에 저장해둔 장소(호텔, 테니스장 등)를 바로 목적지로 선택 가능

📶 통신 · 인터넷 팁

중국 본토에서는 구글(지도·검색·지메일), 인스타그램, 페이스북 등이 차단되어 있어 VPN 없이는 접속 불가합니다.

카카오톡은 원래 차단 대상이었으나, 2025년 11월부터 베이징·상하이 등 일부 도시에서 VPN 없이도 간헐적으로 접속되는 사례가 보고되고 있습니다. 다만 공식 발표 없이 불안정한 상태이므로, 카카오톡으로 연락을 주고받아야 한다면 데이터 로밍/유심과 함께 VPN 앱을 백업으로 준비하는 것이 안전합니다.

본 일정표는 인터넷 연결 없이도 열람 가능한 오프라인 파일이므로, 출국 전 미리 다운로드해두면 현지에서 네트워크 상태와 무관하게 확인할 수 있습니다.

💵 기타 팁

  1. 모바일 결제가 기본이지만, 만약을 대비해 소액 현금(위안화)도 약간 소지 권장
  2. 전통시장·일부 노점은 현금만 받는 경우가 있음
  3. 택시는 디디추싱 호출이 일반 승차보다 편리하고 바가지 위험이 적음
  4. 대부분의 관광지·식당에서 QR 메뉴/주문(스캔 후 직접 주문)이 보편화되어 있음
